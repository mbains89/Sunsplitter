- 112 came from `docs/` and are in this folder; 53 came from `artifacts/` and are in [`artifacts/archive/`](../../artifacts/archive/).
- Before this move, all were last changed between 2026-09-02 and 2026-10-01. Each keeps its file name, so `git log --follow` finds its history.
- To find a receipt by its old path, swap `docs/` for `docs/archive/`, or `artifacts/` for `artifacts/archive/`.

Left in place, though also from before 2026-11-05:
- anything a script, workflow, the runtime, `index.html`, `netlify.toml`, `AGENTS.md` or `CLAUDE.md` names;
- anything whose ticket ID a live page names: STATUS, the ticket queue, ROADMAP, LOCKS, `docs/version-lock.md`, `docs/VERIFY_MODES.md`, README, VERSION, PROGRESS or AGENTS.md;
